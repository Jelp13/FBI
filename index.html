ℹ️ Sobre la App

Esta aplicación consume la API oficial del FBI para mostrar información sobre personas buscadas.

Características:

  • 📡 Datos obtenidos directamente de la API del FBI
  • 🔍 Búsqueda y filtrado de personas
  • 💾 Guardado de favoritos en almacenamiento local
  • 📤 Compartir información sobre personas buscadas
  • 📱 Interfaz responsiva para móviles y escritorio
  • 🚫 Funcionalidad offline con Service Workers
  • 📲 Instalable como PWA
  • ⚡ Caché inteligente para mejor rendimiento

Tecnologías utilizadas:

  • HTML5
  • CSS3
  • JavaScript (ES6+)
  • Service Workers
  • Web App Manifest
  • Cache API
  • LocalStorage para persistencia de datos
  • Fetch API para consultas
